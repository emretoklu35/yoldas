Bitirme projemiz olan Yoldaş: Mobil Araç Enerji ve Destek Hizmeti
Yoldaş, kullanıcıların bulundukları konuma mobil uygulama üzerinden
yakıt, lastik, akü ve şarj desteği çağırabildiği konum tabanlı, yenilikçi
bir araç destek platformudur.
X Projede Kullandığımız Teknolojiler:
• Flutter (Mobil Uygulama)
• Node.js + Express.js (Backend)
• Prisma ORM + MySQL (Veritabanı)
• Google Maps API (Konum Servisleri)
• JWT Authentication (Kimlik Doğrulama)
• lyzico (Odeme Entegrasyonu)
Başlıca Özellikler:
  Gerçek zamanlı servis takibi
  Yakıt, lastik, akü ve elektrikli araçlar için şarj hizmeti 
  Kullanıcı ve admin panelleri 
  Güvenli giriş ve ödeme sistemi
  Kullanıcı dostu ve mobil uyumlu arayüz
